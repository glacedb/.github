# Support

Thanks for using Glace. Here's where to get help:

- **Documentation** — start with the docs site and each repository's README.
- **Questions / discussion** — GitHub Discussions on the relevant repository
  (or [glacedb/glace](https://github.com/glacedb/glace) for general engine
  questions).
- **Bug reports** — open an issue on the affected repository using the bug
  report template. Please include a minimal reproduction.
- **Security issues** — never open a public issue; see
  [SECURITY.md](SECURITY.md).

Support here is community, best-effort support. Commercial support tiers are
available with Glace Pro and Glace Cloud — see https://glacedb.com.
